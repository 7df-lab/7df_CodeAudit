## 使用指引

- **开发前**：01 → 03 → proto → 04
- **开发时**：09 + 08；数值一律查 07
- **测试时**：10（契约测试从 proto 生成）
- **变更时**：先读 13（ADR 流程 + 三条 CI 防线），禁止在 .md 中内嵌 proto、禁止复制 07 数值
