## 3. API 时延基线 <!-- consumers: TP04,TP05,TP08 -->

| 接口类别 | 验收标准 | 高峰负载标准 | 告警阈值 |

| 同步 API（CRUD/查询/鉴权） | P95 <200ms | P95 <500ms | >500ms 持续5min |

**说明**：告警阈值仅对同步 API 生效；原"告警 500ms 高于验收 200ms"的倒挂是因两类 API 混用同一阈值，现已按类别拆分。

## 7. 限流基线（层级递减，网关≤后端）

> **2026-09-01 修订（人类批准，ADR-175/177）**：ai-inference 相关数值行移除/改写——§7 限流行（服务已删）；§8 "DSH→AIInference(Chat)"行删除，"内部超时对齐"中引用已删配置键 `ai_inference.execution_timeout` 的两行合并改写为现行 `step_timeouts_s.verify/missed`（ADR-173）；§10 LLM 降级终点改内置 RuleScan（ADR-175）。

| 层级 | 限流值 |
|------|--------|
| gateway（单用户） | 50 **req/min**（原 50 req/s 作废——高于后端配额的网关限流形同虚设） |

> 校验规则：任一后端服务限流值必须 ≥ 网关到该服务的放大系数 × 网关限流。上线前以压测复核。

### 7.1 账号安全基线（V2.1 ADR-205，2026-09-05 人类指令）

| 项 | 基线值 | 说明 |
|----|--------|------|
| 密码长度 | 8–64 字符 | RegisterUser/CreateUser/ChangePassword 统一校验（INVALID_ARGUMENT） |
| 密码复杂度 | 必含字母与数字 | 同上；服务端与前端双重校验 |
| 密码存储 | bcrypt（默认 cost） | 含种子账号；明文永不落库/落日志（03 §4 V2.1） |
| 一次性临时密码 | 12 字符无歧义字母数字 | ResetPassword 服务端生成，仅响应返回一次；`must_change_password` 强制首登改密 |
| 认证限流 | 沿用 gateway 单用户 50 req/min 总桶 | login/register 独立桶与失败锁定（阈值/时长）为 V2.2 候选，未实现不虚记 |
