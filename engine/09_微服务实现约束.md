## 3. 数据库隔离 <!-- consumers: TP02,TP04,TP08,TP10 -->（7 服务口径，修复 B3；ADR-175/197）

| 数据库 | 归属服务 | 库/schema |
|--------|---------|-----------|
| PostgreSQL `codeaudit_project` | project-service | projects, users, members, configs |
| PostgreSQL `codeaudit_task` | task-service | tasks, stages, saga_log |
| PostgreSQL `codeaudit_result` | result-service | findings, reports, feedback |
| Redis | 共享实例、按服务分 DB | project:0 / task:1 / result:2 / dsh:3 / lock:4 / idempotency:5 |
| MinIO | storage-service 托管 | bucket: reports / cpg / sast-raw |

### 3.1 关键表约束修正

```sql
-- projects 表 scan_mode 约束（4 值枚举，含模式D）
ALTER TABLE projects DROP CONSTRAINT chk_scan_mode;
ALTER TABLE projects ADD CONSTRAINT chk_scan_mode
  CHECK (scan_mode IN ('ai-only','traditional-first','parallel','sast-review'));
```

### 3.2 幂等去重表

```sql
CREATE TABLE idempotency_keys (
  caller_service TEXT, request_id UUID,
  request_hash TEXT, response_snapshot JSONB,
  created_at TIMESTAMPTZ DEFAULT now(),
  PRIMARY KEY (caller_service, request_id)
);
-- 清理：created_at < now() - interval '24 hours'（定时任务）
```

## 4. 并发与队列约束（数值见 07 §6）

- 三级优先队列：高(并发10/超时30m)、普通(30/60m)、低(10/120m)；
- 分布式锁：超时 5min，获取重试 3 次间隔 1s；
- DSH 会话上限 20，会话超时 30m（见 07 §8 内部超时对齐）。

## 5. 限流实现（层级配额，见 07 §7）

- gateway：单用户 50 req/min（令牌桶，Redis 实现）；
- project/task/result：单用户 100/60/60 req/min；
- 违例响应 RESOURCE_EXHAUSTED(8) + Retry-After 头。

## 6. 缓存架构

L1 进程内 Caffeine（TTL 5min）→ L2 Redis（TTL 1h）→ L3 PostgreSQL 持久层。

## 7. 可观测性

- 指标：Prometheus（服务指标 + OpenShell 沙箱指标，见 06）；
- 日志：结构化 JSON，AI 审计日志独立索引、保留 30 天（07 §9）；
- 追踪：OpenTelemetry，trace_id 贯穿 RequestMetadata；
- 告警阈值：见 07 §3/§4（本文档不复制数值）。
